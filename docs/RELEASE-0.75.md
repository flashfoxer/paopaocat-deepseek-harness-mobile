# 泡泡猫 DSH 手机版 v0.75

**本版三件事：① 设置页能「检查更新」 ② 查到就能在应用内下载、验完哈希与签名再交给系统安装
③ 安装包瘦身 41 MB（106 → 65 MB）。**

> 体积口径：下面用 **MiB（1024 进制）**，也就是 App 里显示的那个数；
> 换算成十进制是 **111.5 MB → 68.3 MB**（浏览器下载时看到的就是这个）。

---

## 一、检查更新（设置页第一块，默认展开）

「我知道有没有新版」这件事以前只能靠我发消息告诉你。现在 App 自己去更新源读一份版本清单：
有新版本就显示**版本号、发布日期、包多大、这一版改了什么**。

* **静默**：启动后在后台查一次；三条源依次回退（GitHub 原站 → jsDelivr → 你自填的镜像）。
  全都不通就只写一条日志，界面上如实说"这次没查到"并给出**每一步卡在哪**（想看可以展开）。
  **不弹窗、不挡启动** —— 这类检查最容易变成"每次开机弹一个查不到更新的框"。
* **可关**：设置里能关掉自动检查，那时只有你点按钮才会联网。
* **更新源可自填**：国内直连 GitHub 时好时坏；填错格式当场提示，点「恢复内置源」回到默认。
* **「跳过这个版本」**：只跳过这一版，出了下一版照样会告诉你。

## 二、应用内下载 + 双校验 + 交给系统安装

点「下载到本机」之后的完整链路：

1. **下载**：支持**断点续传**（中断了下次接着下，不用重头来），有进度、速度、可取消。
   文件名会先洗一遍（清单来自网络，防路径穿越），体积上限 2 GB（清单被改成指向大文件时早停）。
2. **校验两样**：
   * **文件哈希** —— 没下坏；
   * **签名** —— 与**当前已装应用**比对（`getPackageArchiveInfo` 读包，与自身签名比）。
     **对不上就不给你装**，这是"更新包被人换成别的"的唯一防线。
     读不出签名、包里没签名、读包失败，**一律判不通过**（拿不到结论 ≠ 可以装）。
3. **安装**：`ACTION_VIEW` + `application/vnd.android.package-archive` + FileProvider
   （`file_paths.xml` 只开了 `updates/` 这一层，没开整个私有目录）。
   差权限时带你去系统的「安装未知应用」页，回来再点。

### 必须说清的边界

* **最后那一下一定要你亲手点**：Android 不允许普通应用静默安装（任何正规 App 都一样）。
  验完之后我们只是把系统安装界面交到你手上。
* **装没装成，我们也看不到** —— 界面上**不会**编一句"安装成功"出来。
  拉起安装界面之后，界面的说法止于"已经交给系统安装界面了"。
* 签名不一致时，**唯一**的办法是卸载重装（数据会丢）—— 界面会把这句原话说出来。

## 三、包瘦身 41 MB

| | 体积 | 说明 |
|---|---|---|
| 0.74 | **106 MB** | 其中 `assets/dsh-runtime.zip` 占 30 MB |
| 0.75 | **65 MB** | −41 MB（−39%），没有删掉任何在用的功能 |

两块来源：

1. **DSH 运行环境（约 32 MB）不再塞进安装包** —— 它每次更新都得重下一遍，纯属浪费流量。
   改成**第一次打开时下这一次**：拉一份几行的 `runtime.json` 清单 → 比 sha256 →
   不对/没有才下载（可续传）→ 在本机解开（约 26,000 个文件）。
   * **装过旧版的人完全不受影响**：那份运行环境早在你手机上了（历次都是随包拷过去的），
     升级到 0.75 **一个字节都不下**、也不会看到「准备运行环境」那一页。
   * **只有全新安装 / 清了应用数据**才需要下这一步（约 32 MB）。
   * 拉不到清单时**不会把你挡在门外**：本地已有 zip 就放行（如实标注"没校验到最新版"）。
2. **本地大模型那一套（LiteRT-LM，11 MB）整个不进包了** ——
   你 0.70 就把入口撤了，却一直占着 11 MB。
   只排除了四个 `.so`（推理本体 + GPU/NPU 加速器）；
   **Java 类与 `LiteRtLmBridge.kt` 都留着** —— 要恢复只需删掉 `build.gradle.kts` 里那四行
   `excludes`，不用改任何代码。真走到那条路时拿到的是 `UnsatisfiedLinkError`（已被 `catch Throwable` 兜住），不是崩溃。

### 顺带纠正一句我之前说错的

上一轮我说"本机 Kotlin 编译卡死、判定为环境问题" —— **真因是我漏了 `GRADLE_USER_HOME=/tmp/gradle-home`**
（项目 `docs/BUILD-LINUX.md` 早写明），结果用了空缓存一直在静默下载依赖。
按文档姿势跑：**出包只要 114 秒**，而且 `assembleRelease` 顺手把 L2 的原生代码也验证了。

## 怎么升级

* **应用内**：设置页 → 「检查更新」→「下载到本机」→ 等它验完 → 「安装」→ 在系统界面上点「安装」。
  覆盖安装，**数据不会丢**。
* **手动**：下载本页的 APK，点开安装即可（同一把签名，可覆盖）。

## 没做 / 还没验的

* **没有真机验证**：新装用户的「下载运行环境 → 校验 → 解压」这条路，
  以及"排除 LiteRT 的 .so 之后 App 能正常启动"，都需要装到设备上走一遍。
* **没有静默安装、没有自动安装**：这是 Android 的规则，不是取舍。
* 还能再小吗？剩下的 65 MB 里，`libnode.so`＋ICU（29 MB）与 `libflutter/libapp`（9 MB）是硬成本；
  ffmpeg（10.5 MB，剪辑/修图）与 ONNX/sherpa（9.4 MB，离线配音）都是在用的功能 ——
  **要到 50 MB 以下必须砍掉在用的功能**（或重新编译 node 用 small-icu）。
