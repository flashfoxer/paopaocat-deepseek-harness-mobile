# 长文速读提炼

本技能负责：把工作区里的一份长文压成「能一眼看完」的速读稿。
什么时候用：用户说「太长读不完 / 帮我速读 / 提炼要点 / 这份报告讲了什么 / 会议记录整理一下」。

产物：`速读-<原名>.md`（必要或用户要求时再给一份自包含 `速读-<原名>.html`）。

## 0. 先确认（一次问完）
- 文件路径？有没有时间范围（只看本周、只看第 3 节以后）？
- 关注点：结论与决策 / 待办事项 / 数字与指标 / 时间线，全要还是某一项？
- 读者是谁（自己回看 / 给别人汇报）——决定写多细。

## 1. 读原文（分段读，别一次刷屏）
```sh
node -e "const t=require('node:fs').readFileSync('长文.md','utf8');console.log('总字符',t.length,'段落数',t.split(/\n\s*\n/).length)"
node -e "const t=require('node:fs').readFileSync('长文.md','utf8');console.log(t.slice(0,4000))"
node -e "const t=require('node:fs').readFileSync('长文.md','utf8');console.log(t.slice(4000,8000))"
```
- 每段 4000 字符左右往后读，直到读完；**不要只读开头就下结论**。
- 文件超长（几十万字符）时，先让脚本按标题/段落切块，逐块提炼，再把结论合并：
```sh
node -e "const t=require('node:fs').readFileSync('长文.md','utf8');const parts=t.split(/\n(?=#{1,3} )/);parts.forEach((p,i)=>require('node:fs').writeFileSync('块'+i+'.md',p));console.log('切成',parts.length,'块')"
```

## 2. 提炼（只用原文里有的东西）
产出必须包含：
1. **一句话结论**：这份材料最想说什么。
2. **要点清单**：5–12 条，每条一句话；重要程度用 `[核心]/[次要]` 标注。
3. **时间线**：把带日期/先后关系的事件按时间排出（没有日期序列就写「材料未给出明确时间顺序」）。
4. **关键数字**：数字 + 它是什么 + 出自材料哪一部分（章节号/小节标题）。
5. **待办与未决问题**：明确的责任人/时间点原样保留（没有责任人写「未指明」）。
6. **写给自己的一句话**：如果只记一件事，记什么。

硬规矩：
- 材料里**没有**的数字、结论、因果关系，一律不写。推断出来的要标「（推断）」。
- 原文自相矛盾的地方单独列一条「矛盾点」，不要替作者选一个。
- 人名、机构名、术语照抄原文写法，不要自己换译名。

## 3. 写文件
用**写文件工具**把结果写到 `速读-<原名>.md`，开头写清来源（文件名 + 字符数 + 你在第 0 步问到的范围）。

需要 HTML 版时生成离线自包含的一份（内联样式，**不引用任何外部资源**）：
```sh
node -e "const f=require('node:fs');const t=f.readFileSync('速读-长文.md','utf8');const esc=(s)=>s.replace(/[&<>]/g,(c)=>({'&':'&amp;','<':'&lt;','>':'&gt;'}[c]));f.writeFileSync('速读.html','<!doctype html><meta charset=\"utf-8\"><title>速读</title><style>body{font:16px/1.7 system-ui;max-width:44em;margin:2em auto;padding:0 1em}pre{white-space:pre-wrap}</style><pre>'+esc(t)+'</pre>');console.log('已写 速读.html')"
```

## 4. 自检
- 要点数是否在 5–12 条之间；时间线是否真的按序；每个数字是否能回到原文某处。
- 对照原文抽查 2 条要点，确认没有把话说过头；抽不准就回去改。

## 5. 交付
回复里直接给「一句话结论 + 要点清单前 5 条」，再给产物**路径原样**。

## 诚实约束
- 读不到文件、编码乱码就贴**真实报错**并让用户重给一份纯文本。
- 这台设备上没有 PDF 解析、没有 OCR 图片识别，也没有 python：`.pdf` / 扫描件如实说做不到，
  替代路径是请用户粘贴正文或另存为 `.txt`/`.md`。
- 不要编造页码、引用编号；引用就引用你自己生成的章节号。
