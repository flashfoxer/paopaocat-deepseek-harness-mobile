# 泡泡猫 DeepSeek Harness（DSH）手机版 v0.76

> **先把名字写全**：**DSH = DeepSeek Harness** —— DeepSeek 官方的智能体运行环境。
> 本 App 是它的**安卓手机版**：把整套运行时装进手机，一句话就能得到**真实文件**
> （`.pptx` / `.docx` / `.xlsx` / 图片 / 视频 / 剪好的片子）。
> 这份发布说明里，第一次出现都写全称，方便没听说过 DSH 的人看懂。

**这一版：修好 20 个问题、新增 17 项功能。**
其中两件最大的是 —— **做 PPT 从"能生成"变成"能拿得出手"**（12 种版式 + 自动排版），
以及 **「不用填 Key 就能聊」重新站住**（免 Key 免费模型 + 联网搜索 + 子智能体）。

> 口径：下面用 **MiB（1024 进制）**，括号里是十进制。计数口径 —— 本文按「修好的问题 / 新增的功能」
> 两类分别计数，**与 App 内「设置 → 关于 → 更新说明」里 v0.76 那一条逐条对应**（同一份文案）。

## 一、修好的问题（20 条）

1. **历史会话点开是空的** —— 看着像对话被删了。真因是"点开聊天页／点了内置会话但没发出去"时 App 已经把会话落盘了，于是列表里堆了一批**没标题、点开全空**的空壳，把真正聊过的对话淹掉。现在空壳**不再产生也不再显示**，工作区那行照实写「磁盘历史会话 N 条（其中 M 条是空会话，没列出来）」—— 一条真对话都不会被藏起来。
2. **切模型会"偷偷换一个会话"** —— 换完模型上下文像丢了。真因是新建会话后**从来没把新 id 写回**运行中的会话句柄，页面一重建就换了新会话。现在切模型只换模型，**会话 id 不变、上下文还在**。
3. **提问失败却看不出为什么** —— 现在会话里直接显示「**没有回答**」并带上原因（网络断了／上游拒绝／超时），回看历史也看得到。
4. **连点发送、或超时之后再发，会白丢一轮** —— 现在超时会**主动取消上一条**（不再让它在运行时那边悬着），连点也不会再叠一轮。
5. **换一家模型之后，会话"只剩一段摘要"** —— 真因是换厂家要重启进程，而重启后历史只被画进一个只读小框、没并进对话。现在历史**直接并进消息流**（按内容去重），同厂家切、换厂家切、退出重进，看到的都是同一条对话。
6. **几个会话来回切之后，点别的功能会窜出会话页** —— 页面栈上以前会压好几个会话页。现在任何时刻**栈上只保留一个会话页**。
7. **会话面板太透明、打字看不清** —— 输入框以前是半透明玻璃层，字压在渐变上。现在全 App 的输入框统一**不透明实底**，并加了一条**对比度门禁测试**钉住它。
8. **长按公众号二维码弹"当前页面无法访问"** —— 真因是微信把这族内部指令封了，而我们还把"有应用接住了"当成成功。现在先核对接住的**是不是微信本尊**，并给三条真正走得通的路：复制公众号 ID、把二维码存相册、仍然试一次唤起微信（结果如实说）。
9. **点猫的那个气泡会崩** —— 它用了负 margin，Flutter 直接断言崩溃（debug 下一画就抛异常）；顺带修掉**设置页长标题在窄屏撑爆整行**、以及**会话回放把运行时的注入说明当成"你说过的话"**显示出来这两处老毛病。
10. **设置模型三处毛病** —— 点一下就像"退出"、名字显示成 id、**只登记前 12 个模型**。现在点进设置不会弹回去、名字显示真名、**模型全量登记**（要去掉上限就全去掉）。
11. **首次启动还催你去填 Key** —— 现在免费模型**开箱即用**：首启就登记好，提示里也不再叫用户去配一个根本不需要的 Key。
12. **DeepSeek 的兜底名单与联网搜索的模型名过期了** —— 官方把 V3/R1 改成了 V4；名单和搜索后端都跟着改名（否则选了就是 404）。
13. **免 Key 通道里有一条模型被漏算成"付费"**（`big-pickle`）—— 现在**免 Key 通道里的模型一律算免费**，排序也跟着修。
14. **保存偶发丢更新**（日志里抓到的真问题）—— 两次保存挨得很近时，两次抢同一个临时文件，先完成的把它改名走，**后一次直接失败、那次更新就悄悄丢了**（真机上相隔 21 毫秒）。现在临时文件**一物一名**，并补了一条"同时保存三次必须有一次完整落地"的回归测试。
15. **覆盖安装后拿不到新的运行环境** —— 运行环境内容版本 1 → 2，覆盖安装也会重新解压，装完就是带联网搜索后端的那份。
16. **完整包装完还要再下 32 MB 运行环境**（新装没网就打不开）—— 完整包现在**直接用包里自带的那份**，不联网、不再多下。
17. **免 Key 通道被上游连着改了两次**（2026-10-15 的第 5 次、第 6 次门禁）—— 按最新契约全部对齐：端点、会话头、**工具指纹从两个变四个**、请求 id 形状、**真流式**，并在本机实测通了（不再"看着配好了、一发就失败"）。
18. **「通道自检」会假通过** —— 它原来只问"模型清单拉得到吗"，而这道门禁**清单永远能拉到**，用不了也报"好的"。现在它会**真发一句 1 个字的话**，并把两种 403 分开说：**「被当成非官方客户端」**与**「你所在地区不开放」**（下一步完全不同）。
19. **口播／短剧／剪辑／配音在 0.75 的包里会失败** —— ffmpeg 那一套 **10 个运行库在出包时丢了**（它们不在代码里、也不是依赖包，是本地编好后放进构建目录的，重建构建目录时被覆盖）。编译期毫无征兆、测试也照过 —— 是"只认包里字节"的出包核对脚本拦住的。现在补回并留了持久副本，出包核对也能拦住同类问题。
20. **出包核对脚本自己在假红** —— 它一直要求本地大模型那四件 `.so`"必须在包里"，而那四件已按你的决定（本地模型不用了）从包里拿掉，于是每次出包都 FAIL。假红和假绿一样有害，已改成"按决策刻意不随包、只报信息"。

## 二、新增的功能（17 条）

1. **「不用填 Key 就能聊」重新站住** —— 新增 **Pollinations** 通道并**默认开启**：它自己就开放匿名层（不用注册、不用 Key），装完模型列表里就有「免费模型（无需 Key）」那一组，直接能聊，也能随时关掉。
2. **会话里的 AI 现在能自己去查资料了**（联网搜索）—— 走 AnySearch 后端，问它"最新情况"它会真去搜，并把来源带回来。
3. **子智能体** —— 可以让 AI「分人做事」：把一件事拆给几个子任务并行做完再汇总，长任务不用你盯着一轮轮点。
4. **「记忆」从一句输入框变成一套真正的记忆** —— 每条能标分类（身份／偏好／项目与事实／不要做的事／其它）、重要度、作用范围（全局或只在某个工作区），能搜索、置顶、一键关闭注入、导入导出 JSON；还能**从最近会话里提炼候选**，由你逐条勾选确认后才写入（它不会背着你偷偷记）。
5. **外观新增壁纸** —— 从相册选一张铺满，配「变暗」与「模糊」两个滑块（它们不是装饰：卡片是半透明的，背景一亮字就难认）。也有一键「不用壁纸」。
6. **会话列表能看到时间和用了多少 token** —— 一眼知道哪条是刚聊的、哪条吃 token 多。
7. **首页版本号下面多了一条滚动信息栏** —— 公告直接写在仓库里，改了所有人下次启动就能看到。
8. **点一下首页那只猫，它会说话** —— 泡泡在左／上／右轮流出现并伴随短震动；**连点 7 下有彩蛋**（长震 + 三个泡泡）。
9. **像素主题整容**（不只是换色 + 直角）—— 等宽字体、2dp 描边、不透明实心板、硬方块投影、扫描线、关掉水波纹。
10. **「工作台」改名叫「创作台」**，并且入口屏**按 4 组分类、可收起**（「项目太多，是不是也分类」）—— 不展开时一屏看完，找什么再展开哪一类。
11. **创作台新增「APP 界面设计台」** —— 在手机上画界面草图（Material 3）再导出成给 AI 的描述；**连字体和图标字体都随包**，打开即用，拖得动、按得中（命中区最小 44×44）。
12. **做 PPT 从"能生成"变成"能拿得出手"** —— 12 种版式（封面／章节／目录／要点／**卡片**／**时间线**／**两栏对比**／**关键数字**／**数据图**／引用／**配图**／结尾）+ **自动排版**：字多了自己收字号（正文有 12pt 可读下限，再放不下就自动拆「（续）」页）、卡片按条数分栏、图片按比例入框；6 套配色、页脚页码自动处理、可选换页转场。产物是**原生形状**，在 WPS / Office 里能改颜色改字。
13. **创作台新增「做 PPT / 幻灯片」入口** —— 点开有 4 个可直接用的例子（工作汇报／教学／路演／两方案对比），点一个就开会话，起始指令已经点名了对应技能。
14. **模型列表全量登记**（不再只登记前 12 个），并**把带 free 的排前面** —— 免费的先看见。
15. **模型列表能标出哪条模型「看图」** —— 从模型卡片的 `input_modalities` 读出来，选之前就知道哪条能吃图。
16. **「通道自检」新增：一键把结论发给开发者** —— 一键生成一份不含 Key 的报告并拉起分享，卡在哪一步一眼看得见。
17. **长会话助手** —— 上下文快用满时主动提示你（"该开新会话了"），不再莫名其妙变傻。

## 四、怎么升级

* **应用内**：设置 →「关于」→「检查更新」→ 下载（可断点续传）→ 本机**双校验**（文件哈希 + 与已装应用比对签名）→ 交给系统安装 → 在系统界面上点「安装」。**覆盖安装，数据不丢。**
* **手动**：下载本页 APK 点开安装（同一把签名，可覆盖）。
* ⚠️ 如果你装过 **2026-10-15 那批 0.75 测试包**（文件名带 `20261015a`~`h`）：那批包**缺 ffmpeg 那一套运行库**（口播 / 短剧 / 剪辑 / 配音会失败），本版已补回，请直接覆盖安装。

## 五、诚实边界（写清楚，不夸大）

* **App 里看不了 `.pptx` 的样子**（没有 Office 组件）—— 生成后在「资料库」里用「用其它应用打开」交给手机上的 WPS / Office，或者直接分享。
* **PPT 里的数据图是用形状画的**（柱 / 条 / 堆叠 + 数值标签）：能改颜色尺寸、一眼看懂，但**不是** PowerPoint 的"图表对象"，改数据要重新生成；**没有**逐元素动画与音频嵌入，只有换页转场。
* **免 Key 的免费模型是"够用"级**：免 Key 那条通道只有一个 20B 级模型；要写长文 / 复杂推理，请配自己的模型（DeepSeek / 智谱 / 百炼…都支持）。
* **应用内下载走 GitHub**：国内直连有时不稳（镜像救清单、救不了包），退路是「改用浏览器下载」。
* **还没有真机验证的部分**：全新安装装完整包后解压运行环境、应用内"下载 → 双校验 → 安装"整条链、以及**本版补回的 ffmpeg 真跑一次**（本机没有安卓设备，只能证明"运行库都在包里且是 AArch64 ELF"）。
