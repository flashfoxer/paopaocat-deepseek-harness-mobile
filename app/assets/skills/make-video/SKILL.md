# 生成一段视频

本技能负责：把一段画面/动作描述变成工作区里的真实 `.mp4` 文件。
什么时候用：用户说「生成一段视频 / 做个动态短片 / 让这张图动起来」。

## 0. 先确认（一次问完）
- 画面主体在做什么（动作是视频的核心，比画面风格更重要）。
- 时长（4–12 秒，默认 5 秒）与画幅（16:9 默认 / 9:16 竖屏 / 1:1）。
- 有没有参考图或首帧图（工作区文件名或 URL）。

## 1. 写提示词
顺序：`主体 + 具体动作 + 镜头运动（推/拉/摇/跟拍/固定）+ 环境与光线 + 风格 + 节奏`。

示例：
```
一只橘猫在木桌上伸懒腰然后跳下桌面，镜头缓慢右移跟随，
午后暖光，写实风格，动作自然连贯
```

要求：
- 只写**一个连续动作**；写「先…然后…再…」通常会导致动作变形。
- 视频里**不要要求出现文字/字幕/logo**，模型基本写不对。
- 时长越短越稳；4–8 秒成功率最高。

### 1.1 八个维度（照着填，缺哪格就在哪格翻车）

视频提示词与图片最大的区别是：**图片只要"画面对"，视频还要"动得对"**。
写之前先扫一遍这八格：

| 维度 | 要交代什么 | 不写会怎样 |
|---|---|---|
| ① 主体动作 | 谁在做什么，**幅度与速度**（缓慢伸手 / 猛地转身 / 轻轻眨眼） | 模型自己挑一个动作，通常不是你要的 |
| ② 表演与表情 | 人/动物的情绪神态（微笑、皱眉、喘气、看向镜头） | 面瘫、眼神空洞 |
| ③ 镜头运动 | 推 / 拉 / 摇 / 移 / 跟拍 / 固定镜头，以及快慢 | 默认轻微飘移，看着不专业 |
| ④ 环境运动 | 风、水、烟、云、人群、光影移动 ——**画面里"别的东西也在动"才像活的** | 背景死板，像一张图在轻微变形 |
| ⑤ 时长与节奏 | 几秒（4–12，默认 5）、匀速还是先慢后快 | 动作被截断或没演完 |
| ⑥ 起止状态 | 开头什么样、结尾停在哪（**关键帧模式必填**） | 首尾帧对不上，动作突跳 |
| ⑦ 口型/说话 | 有人开口时：说什么、什么情绪 | 嘴型乱动 |
| ⑧ 不要什么 | 文字、字幕、水印、logo、多余主体、换脸 | 画面里凭空多出人手或字 |

**八格齐全的示例**：

```
一只橘猫趴在木桌上，缓缓伸懒腰后轻盈跳下桌面（①动作），
眯眼打了个哈欠、尾巴轻摆（②表演），镜头缓慢右移跟随（③镜头），
窗外树叶随风轻晃、尘埃在光柱里浮动（④环境运动），
午后暖光，写实风格，动作自然连贯、节奏偏慢（⑤节奏 + 风格）
```

**提交前自检**（①②③ 必须有内容）：

```
① □ 明确写了"在做什么"，且只有一个动作
② □ 写了神态/情绪（画面里有人或动物时）
③ □ 写了镜头怎么动（或明确写"固定镜头"）
④ □ 画面里还有别的东西在动吗？有就写明
⑤ □ 时长够不够把这一个动作演完
⑧ □ 交代了"不要文字/水印"吗
```

## 2. 提交生成（异步，耐心等）
```sh
node "$DSH_ANDROID_TOOLBOX/make-video.mjs" "提示词" "输出.mp4"
node "$DSH_ANDROID_TOOLBOX/make-video.mjs" "提示词" "输出.mp4" --seconds 5 --ratio 16:9
```
- `--seconds`：4 到 12（字符串秒数），默认 5。
- `--ratio`：默认 16:9，也常用 9:16（竖屏）。
- 脚本自己提交任务并轮询（默认可能轮询到约 10 分钟），**只会返回一次结果**。

进阶（一般用不到）：
```sh
node "$DSH_ANDROID_TOOLBOX/make-video.mjs" "提示词" "输出.mp4" --mode keyframe --first-frame "首帧.png"
```
- `--mode` 可选 `text`（默认）/ `keyframe`（给 `--first-frame` 或 `--last-frame`）/ `reference`（给 `--image` / `--audio`）。
- 模式互斥，脚本会在发请求前本地拦下不合法的组合。

## 3. 等待期间的两条铁律
- **不要在轮询期间重新提交同一个任务**，重复提交会重复排队、白等更久。
- **不要一边等一边又开一条命令查进度**（脚本已经在查了）；也不要中途 `kill`。
  单次命令可能要跑几分钟，这是正常的，把这一步跑完再继续。

## 4. 自检
```sh
node -e "const b=require('node:fs').readFileSync('输出.mp4');console.log('字节',b.length,'ftyp',b.subarray(4,8).toString())"
```
- 大小应为几十 KB 以上，第 4–8 字节是 `ftyp`（mp4 的标志）。
- 没生成成功就别交付路径。

## 5. 交付
回复里给：**路径原样**、时长与画幅、提示词摘要，并说明生成耗时较久是正常的。

## 诚实约束
- **绝不编造视频链接或文件名**；没跑出文件就如实说失败。
- 失败（超时、额度、内容被拒）就把脚本的**真实报错**贴出来：是轮询超时还是任务 `failed`。
- **本机有 ffmpeg**（随包，`ffmpeg` / `ffprobe` 直接可用，见 AGENTS.md 的「本机可执行的执行环境」）——
  所以**能**做：转码、改尺寸/码率、截取片段、拼接多段、抽帧、转 gif、加音轨、调音量。
  做不到的是**生成**（画面本身只能靠 `make-video.mjs` 提交给平台）。
- 要**烧字幕**不行（随包的 ffmpeg 没编进 `subtitles` / `drawtext` 滤镜）；需要字幕就走
  「影视 → 口播/短剧」，那里字幕由 App 侧画好再合成。
