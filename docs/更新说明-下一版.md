# 发版素材与内部事项

> ⚠️ **用户能看到的「更新说明」不在这里。**
>
> 「随包一起发」的那份，唯一落点是 **`app/lib/data/changelog.dart` 里的 `kChangelog`** ——
> 它是 Dart 源文件，会**编译进 App**，装上就能在「设置 → 关于 → 更新说明」读到。
> **每改一个功能、每修一个 bug，就往那里的「下一版」条目加一条。**
> 有一条专门的测试（`app/test/changelog_test.dart`）会拦住"忘了写"这件事 ——
> 那不是靠自觉，是靠 `flutter test` 变红。
>
> 写进 markdown **不算**：`docs/` 下的文件不会进包，用户看不到。
>
> 这个文件只放两类东西：
> 1. **发版时写长文要用的素材**（GitHub Release 说明、公众号稿里的细节与措辞）；
> 2. **内部事项**：不面向用户的改动、修正、待办。
