## 一、Key 无效这类失败，现在会说人话

### 1.1 那位用户实际看到的

他切到 `com/deepseek/deepseek-v4.1-flash`（Command 聚合）后连撞 4 次 401：

```
prompt failed（第 1 次）: Bad state: session/prompt 失败：Internal error: turn failed:
  401: {"message":"Invalid 'Authorization' header or token.",
        "type":"authentication_error","code":"UNAUTHORIZED"}
```

而界面上他能看到的只有：

> 这条没能回上来。可以再发一次；若反复如此，去「设置 → 运行日志」看细节。

**这句建议对 401 是错的**：App 自己已经自动重试过一轮（日志里「第 1 次 / 第 2 次」），
他手动再来一轮 —— 一共白试 **4 次**。

### 1.2 为什么没翻译

`data/api_error_text.dart` 里的 `translateDshError()` 负责翻译"DSH 抛回来的英文串"，
但它只认四类：**上下文不够 / 缺凭据 / 模型未注册 / 沙箱**。

ACP 回来的 `turn failed: 401: {…}` **一类都不匹配** → 返回 `null` →
调用方只能给通用文案。

**最冤的是**：401 的人话早就写好了 —— 就在同一个文件的 `translateHttpError()` 里：

> API Key 无效或没填。请回设置页检查 Key，并确认它属于当前选中的服务商。

只是**这条路碰不到它**。

### 1.3 修法：加一条兜底，把 HTTP 码从原始串里抠出来

```
translateDshError(raw)
  ⓠ …原来的四类…
  ⓔ 新：匹配 `\b([45]\d\d)\b\s*:\s*\{`  或  `turn failed:\s*([45]\d\d)\b`
       → 交给 translateHttpError(statusCode:, body: raw)   ← 复用已有的人话
       → 都对不上：仍然返回 null（**不许凭空编一个原因**，有测试钉着）
```

### 1.4 顺带：不该重试的失败不再重试

重试循环以前只排除「超时 / 用户取消 / 进程没了」，
于是 **401、404 这类"配置就不对"的失败也会傻乎乎再试一遍**。

现在判据直接用翻译层的 `retryable`：

| | 行为 |
|---|---|
| 429 / 5xx / 连不上端点 | 照常重试（重试是对的） |
| 401 / 402 / 403 / 404、缺凭据、模型未注册 | **一次就停** |

**为什么用 `retryable` 而不是在这里再写一遍状态码**：两套规则必然跑偏 ——
这正是 0.66 修提示词专家 400 时踩过的同一个坑（那时把规则抽成一份）。

## 二、自定义厂家的 id 不再撞成同一个 `provider`

### 2.1 那份日志里的痕迹

那位用户把「书生·端砚」（`discovery-api.intern-ai.org.cn`）加成自建厂家，
日志里处处是：

```
自定义厂家 Key 已写入安全区：provider=provider
自定义厂家已写盘：provider=provider 0→9 个模型
```

**它的 id 就叫 `provider`。**

### 2.2 原因与后果

`sanitizeProviderId()` 把非 `[a-z0-9_.-]` 的字符换成 `-`，
然后掐掉首尾的 `-`。**纯中文名字换完是空的** → 兜底成固定的 `'provider'`。

后果三条：

1. **再加一家纯中文名字的厂家 → id 相同 → 在 `models.json` 里互相覆盖（真丢数据）**；
2. 安全区 key 变成 `dsh_provider_key_provider`、环境变量变成 `PROVIDER_API_KEY`；
3. `provider` 又恰好是解析坏数据时用的**哨兵值**，真假分不出来。

### 2.3 修法

* 新增 `ConfiguredModels.uniqueProviderId(preferred, taken:)`：
  推不出有意义的名字、或推出来已被占用时，改用
  `custom` → `custom-2` → `custom-3`…；**永不返回已占用的名字**；
  并让开 `rotate`（轮换组占用）与 `local`（本机模型的虚拟厂家）两个保留名。
* **让用户看得见**：那个输入框的说明写着「留空就按厂家名生成，例如 qwen」——
  而中文名推不出字母。现在框下面**实时显示**：

  > 留空 → 会生成 provider id「custom」（中文名推不出字母，所以自动编号）

  推导与保存走**同一个函数**，预览不会和实际结果分叉。
