先说声抱歉

今天大家在手机上实测报的问题，大部分已经修好了 —— 这一版是紧急更新。但想先说清这版为什么会来：不是上得急，是想简单了。

DSH 原本是跑在电脑上的（桌面版）。它能读文件、能跑命令、能调用一堆现成的工具，靠的是电脑上本来就有的那套东西：shell、python、字体排版、本地的语音模型……这些在电脑上都是"系统自带"，搬到手机上一个都没有。所以把 DSH 装进手机从来不是"下一个包"的事，而是要把这些依赖一个一个地重新匹配：有的是重写（手机上用的是系统自带的 sh，写了一层壳去接住原有的调用），有的是换替代品（Word/PPT 那种桌面排版库手机上没有，改成内置 Node 脚本自己生成），有的根本没有 Android 版本（后面语音那条就是）。

按"电脑上能跑，手机上也该差不多"的思路估了这件事，想简单了。昨天那一版就是这么发出去的，而大家遇到的三类问题，本质上是同一件事：一次改动牵动了三条链路（界面 → 运行时配置 → 子进程执行环境），而只验证了其中一条。

· 画图用不了 —— 会话这条链路绕过了统一的执行环境，自己拼了一份精简的环境变量，没带上 Android 上的 shell 垫片；而手机上没有 bash，系统只会去调 bash。于是大家点「生成一张图片」，拿到的是 spawn bash ENOENT。同一个 App 里，定时任务那条链路走的是完整环境，一直是好的 —— 两条路不一致，是没对齐。

· 切模型要选两次 —— 选中项还没落盘，界面就先去重写运行时配置了；切不过去需要重建会话时，又没先把新模型写进配置。两处都是顺序问题，跟网络、跟大家的手机都没关系。

· 三个点不开的"产物" —— 产物卡片是从工具输出里"认文件名"认出来的，结果把 App 内置技能文档里的示例占位名（输出.png、参考图.png）也认成了"刚生成的文件"。图还没出来，先冒三张卡片；一直到图生成完，这三张都点不开，大家只能在资料库里找那张图。

这三条今天都改好了，而且是拿证据改的：在模拟器上造了一个"第一个模型永远失败、第二个正常"的假上游来验证模型轮换，又造了一个"真产出一个文件、只回声那句示例"的假模型来验证产物 —— 每一条修复都能复跑、都有截图。

还有一条没修完：语音识别

大家反馈过"语音识别无法使用"。这条还没修好，如实交代已经试过的几条路：

1. 最早只有一条路 —— 把系统的语音识别界面拉起来（ACTION_RECOGNIZE_SPEECH）。手机上没装可用的识别服务时（不少国产 ROM 没带 Google 语音、厂商服务又不响应），它直接失败，大家只看到一句"没识别到"。

2. 补上麦克风权限（0.12）—— 改成 App 自己录音后，没有录音权限会直接返回 error=9。这里还做细了一步：只在真的会用到时才申请，走系统识别那条路时不白弹一次授权。

3. 改走 Android 12 以上的"设备端离线识别" —— 优先用系统预置的离线模型（不联网也能用），识别不到再回退到第 1 条那条系统路；两条都失败会分情况说清是"没有离线模型""没有识别服务"还是"没听清"，不再含糊。

4. 试过内置本地识别（DSH 自带的那套本地语音模型）—— 走不通：它的原生库只提供 macOS / Linux / Windows 版本，Android 用的是另一套 C 运行库（bionic），不在支持列表里；而且 int8 模型有 239MB，塞进手机包也不现实。

所以还在查：到底是系统的识别服务没被暴露出来，还是设备端的离线模型没装。没修好的不糊弄：按住说话要是用不了，就是没修好，不用一句"暂不支持"盖过去。

也是在这件事上最想补一句：这是第一次做这么复杂的 App，很多地方是边做边学。想简单了，代价就是大家在手机上替撞了这些坑。还请原谅 —— 遇到问题直接在这里留言，下个版本就改。

一、这一版（0.14）改了什么

1. 产物里，只出现真正生成的文件

先说清以前发生了什么。

大家让模型画一张图，会话里会立刻冒出三个"产物"卡片；一直到图片真的生成出来，这三张卡片一张都点不开，大家只能在「资料库」里翻到那张图。

那三个名字其实是内置技能文档里的示例：文档里写着 node make-image.mjs "提示词" 输出.png，界面就把这句示例里的 输出.png、参考图.png，连同一段自检命令，都当成了"刚生成的文件"。

现在产物必须过两道门槛：文件真的在工作区里存在，而且是这次会话写出来的。两条都满足才会出现在产物里 —— 点开就是文件本身，能直接看、直接分享。

图 1 · 产物列表，只剩真实存在的那一个文件

图 2 · 点那张卡片，直接打开文件预览

2. 会话页右上角，改成「工作区」

以前那个按钮点进去是「模型设置」。现在它是「工作区」：点一下直接看到有哪些工作区、每个工作区下有哪些会话，可以切换工作区、恢复历史会话 —— 和首页右上角那个是同一个页面，不用再退出去找。

顺带把"当前在哪个工作区"写在顶栏第二行：本机 · 工作区名。

图 3 · 会话页右上角的工作区入口

图 4 · 点进去就是这一页：工作区 + 每个工作区下的会话

模型设置没有丢：底部导航的「设置」Tab 一直在，会话页里的「去设置」也还在。

3. 「设置 → 外观」的说明文案重写了

以前那段说明里写着"对齐某网站"，现在只讲本 App 两套皮肤各自长什么样。

图 5 · 设置 → 外观

4. 窄屏手机的顶栏不再挤出屏幕

320 像素宽的老机型上，会话正在跑、并且已经有产物的时候，右上角会挤出屏幕 30 像素。已经修好，并在 320 像素宽下加了自动检查，防止以后再被改回去。

二、今天一共发了 6 个版本（0.09 → 0.14），全部更新项目都在这儿

今天是一整天连着发的：0.09 → 0.10 → 0.11（内部验证版，没单独发）→ 0.12 → 0.13 → 0.14，加起来 35 条改动。上面 5 条是 0.14 的，下面这些是今天早些时候发的。

0.13 · 会话里终于能跑命令了

· 把「会话里跑命令」这条链路修好了：此前会话这条链路自己拼了一份精简的环境变量，没带上手机上的 shell 垫片，而手机上没有 bash —— 所以画图、生成 PPT、凡是需要 App 执行命令的事都会失败。现在会话与定时任务走的是同一套执行环境。

· 在会话里接通了内置工具箱（生图 / 生视频 / 生成 .pptx），大家不用再自己装终端。

· 把「切换模型」改成点一次就生效（此前是先通知、后落盘，顺序反了，所以要选两次）。

· 让切换模型以运行时回报的结果为准，不会出现"界面说切了、实际还在用旧模型"。

· 在「分享运行日志」的弹窗里写上了开发者邮箱（可长按复制），大家导出的日志知道该发给谁。

图 6 · 会话里真的在跑命令，产物里就是那个文件

0.12 · 模型与 Key 那一批问题

· 修好了「填了 Key 却提示没凭据、模型用不了」：会话启动时会把每个厂家各自的 Key 正确交给运行时。

· 让改了 Key 或端点之后新配置真的会生效（App 会重建会话）；只换一个已经登记过的模型则保留当前会话与聊天记录。

· 让会话里的默认模型以设置里的为准，两处不再各说各话，重启也不变。

· 按大家反馈的方案重排了模型设置区：「我的模型」是几张内置厂家的卡片，点开是介绍 → 去注册 → 获取模型，只要填 API Key 再点「测试并保存」；下面是「添加模型」；最后是「轮换池」。

· 保证「测试并保存」成功后一定会登记到模型（拉不到真实列表就用内置建议模型，并如实说明）。

· 把会话里的模型面板改成两级：先按厂家分组（含「轮换池」一组），点厂家看到它的模型，点模型就切换使用。

· 补上了语音输入的麦克风权限；设备端识别失败会回退到系统识别界面，实在没有识别服务时说清原因。

· 新增了「运行日志」：设置 → 关于里可以一键生成，导出到文件或用系统分享发出去；日志里的 API Key 会自动脱敏。

图 7 · 设置 → 模型：轮换组 / 添加模型 / 内置 Agnes

0.10 · 界面换成新风格（可切浅色 / 深色）

· 让会话里切换模型不再重建会话：聊天记录保留，成功时提示「已切换到 X（会话保留）」。

· 把首页内置会话改成 4 个一组，「换一换」一次换一整组，点 3 次就能看完 12 条。

· 把语音输入改为优先使用手机自带的离线识别（Android 12 及以上），识别不了再回退到系统识别，识别语言跟随手机语言。

· 把界面按新风格重做：「设置 → 外观」可以切浅色 / 深色，点一下立即生效、重启后保持。

· 把「设置 → 外观」里的「自定义」如实做成占位：点了会说明还没做，不会把主题切到一个不存在的状态。

· 重排了模型设置页：当前模型 → 我的模型 → 轮换组 → 添加模型（默认收起）→ 内置 Agnes，一眼就能看到现在用的是哪一个。

· 把「插件」那一栏改成实话：插件安装暂未开放（要先做完安全校验与回滚机制）。

图 8 · 浅色主题的首页

0.09 · 产物、网页、PPT、多厂家、轮换组

· 把产物接上了系统分享面板：点「分享」就能把文件发给微信等其它应用。

· 让 HTML 产物点开直接渲染成网页（也能「查看源码」「浏览器打开」），不再显示一屏代码。

· 大家要 PPT，就给真的 .pptx 文件（App 内置了生成脚本），不再拿 HTML 顶替。

· 在第一次安装、还没配模型时给出明确指路：「开始会话」不再点不动，而是告诉大家要先去设置里配一个模型。

· 让一台手机可以同时配多家服务商，各家互不覆盖；「获取模型」支持多选，勾好一次性加进来。

· 新增了「模型轮换组」：几个模型按设定好的顺序依次尝试，前一个被限流（429）就自动换下一个。

· 内置了 Agnes（免费）：生图 / 生视频的端点和注册地址写在设置里，要图片、要视频时自动调用；没填 Key 会如实报错并给出注册地址。

· 把首页内置会话从 4 条扩到 12 条（每条带一个技能）。

· 把安装包命名统一成 paopaocat-preview-版本-芯片 这一种写法。

· 让屏幕边缘侧滑不再一下就退到后台：第一次只提示，再滑（或再按返回）一次才退。
