## 一、安装包与交付流程（第 3–8 条）

3. 统一了安装包命名规则：`paopaocat-preview-<版本>-<芯片>[-debug].apk`，
   并把生成脚本改为**从 `app/lib/app_version.dart` 读取版本号**，使包名与界面显示的版本号只有一个真源。
   —— `install/build-local-apk.ps1`
4. 在打包脚本里增加了交叉校验：`pubspec.yaml` 的 `versionCode` 必须等于版本号去掉小数点后的整数，
   否则告警（Android 只允许覆盖安装版本码更大的包）。 —— `install/build-local-apk.ps1`
5. 为每次交付做包内容核验：用 `aapt dump badging` 读 `versionCode` / `versionName` / `native-code`，
   用 `apksigner verify --print-certs` 比对签名指纹，确认"只有目标 ABI、签名与上一版一致（可直接覆盖安装）"。
   —— `install/inspect_apk.py`、`docs/logs/badging.txt`
6. 确认了一个容易误判的事实：Dart AOT 快照里**中文以 UTF-16 存储、ASCII 以单字节存储**，
   因此验证"新文案是否真的进包"必须在 `lib/arm64-v8a/libapp.so` 里按 **UTF-16** 检索；
   按 UTF-8 检索会得到"没进包"的错误结论。 —— `docs/HANDOFF.md`
7. 为模拟器单独产出 x86_64 debug 包，并保留一个只服务 `dist/` 的极简 HTTP 下载服务，
   便于手机在同一局域网内直接下载安装。 —— `install/serve-apk.mjs`
8. 把今天每次构建与设备验证的输出固化到 `docs/logs/`，形成可复跑的取证链（不依赖"记得测过"）。

## 二、运行时与执行环境（第 9–14 条）

9. 定位到"会话里任何命令都跑不起来"的根因：会话链路**自行拼装了一份精简环境**，
   既没有加载 Android 执行垫片，也没有注入 `DSH_ANDROID_*` 四件套与工具箱路径；
   而定时任务链路走的是完整运行时环境 —— 同一 App 内两条链路不一致。 —— `docs/RELEASE-0.13.md`
10. 编写了 Android 执行垫片 `android-exec-shim.cjs`：把对 `bash` 的调用改写到 `/system/bin/sh`（mksh），
    并把随包的 Node 运行时、工具箱目录注入 shell 环境，使原有的 `bash -c "…"` 调用在不改动上层脚本的前提下可用。
    —— `app/assets/toolbox/android-exec-shim.cjs`
11. 让会话链路**复用整份运行时环境**（`DshRuntime.environment` + execShim + 启动前
    `AndroidToolbox.ensureInstalled`），使两条链路的行为完全一致。 —— `app/lib/local/dsh_runtime.dart`、`acp_client.dart`
12. 补了工具链自检：在设备上分别验证 shell 改写生效（`DSH_SHIM_OK`）、
    Node 可用（`NODE_OK v26.4.0`）、工具箱脚本可列出并执行。 —— `install/fix13_fake_model.py`、`docs/RELEASE-0.13.md`
13. 如实记录了设备侧硬限制：Android 内核未启用 landlock，**shell 沙箱不可用**（模型会自行降级为文件工具）；
    设备上没有 python / pandoc / libreoffice / ffmpeg，相关能力一律用随包 Node 脚本替代。 —— `docs/HANDOFF.md`
14. 整理了设备侧 quoting 与路径陷阱：中文路径会让 `aapt`、`keytool -printcert` 失败；
    `adb shell` 嵌套引号会被 PowerShell 吃掉 —— 一律改为先 `adb push` 脚本再 `run-as <pkg> sh <脚本>` 执行。
    —— `docs/HANDOFF.md`

## 十一、这些文档里指出的硬限制（第179–197条）

179. 无法在中文（非 ASCII）路径下构建或分析：Gradle 会直接报 "Your project path contains non-ASCII characters"，`flutter analyze` 会因路径百分号编码后字节数错位报 `FormatException: Unterminated string`。
180. 在 PowerShell 5.1 下无法用 `Get-Content -Raw` 安全读无 BOM 的 UTF-8 文件（按 ANSI 读成乱码，`Set-Content` 写回即永久损坏），所以 `.ps1` 必须纯 ASCII、Dart 源码一律用编辑工具改。
181. Gradle 官方发行源在本机不可达（实测 fetch failed），必须走腾讯镜像。
182. Kotlin 增量编译在本机环境下无法工作（`flutter clean` 后仍复现），必须整体关掉、牺牲 1–2 分钟构建时间。
183. `$ErrorActionPreference = 'Stop'` 会让 Flutter 的 stderr 镜像提示变成 `NativeCommandError` 并中止脚本。
184. 无法从 `defaultConfig.ndk.abiFilters` 拿到目标 ABI（被 Flutter 插件覆盖），只能用 `packaging.jniLibs.excludes` 排除。
185. 无法把 `-P` 或 `ORG_GRADLE_PROJECT_*` 可靠地传给 Gradle：Flutter 不转发 `-P`，Gradle daemon 又缓存进程环境，最终只能写进 `gradle.properties` 并 `gradlew --stop`。
186. Android 只允许从 `nativeLibraryDir` 执行原生程序：App 私有目录里的可执行文件会被 SELinux 拒绝，`/data/local/tmp` 虽可执行但正式 APK 不能用它，所以 node 必须以 `libnode.so` 进 jniLibs。
187. 不以 `.so` 结尾的库名（`libcrypto.so.3` 等）无法作为 jniLibs 打包，必须改名并对所有 ELF 做等长 `DT_NEEDED` 字符串替换。
188. AGP 拒绝在 manifest 里写 `extractNativeLibs="true"`，只能改用 `packaging.jniLibs.useLegacyPackaging`；否则 `nativeLibraryDir` 为空、`libnode.so` 无法执行。
189. 从 `AssetManager` 流式 `ZipInputStream` 解压在 26495 条目的 zip 上只能解出 3 个条目，必须改用 `ZipFile`。
190. .NET 在 Windows 上写出的 zip 条目名用反斜杠、不符合 zip 规范，Kotlin 侧必须统一替换。
191. 涉及路径的 Kotlin KDoc 注释（`app/**`）会触发嵌套注释、导致 `Unclosed comment` 编译失败。
192. Android 内核未启用 landlock，shell 沙箱不可用；设备上没有 python / pandoc / libreoffice / ffmpeg，相关能力只能用随包 Node 脚本替代。
193. `node-pty` 与 `sharp` 都没有 Android 构建，只能依赖 `createLazyRequire` 懒加载、降级行为仍需逐工具确认。
194. 首启解压是必须接受的体验代价：26495 个文件约 75 秒，且当前进度回调是限频上报、还需要"可跳过"设计。
195. ACP 不发 artifact 通知：`session/update` 只有 `agent_message_chunk` / `agent_thought_chunk` / `tool_call` / `tool_call_update` / `usage_update`；产物只能由客户端自己在工作区核实（存在性 + 修改时间晚于会话开始）。
196. ACP 的 `session/list` 不给标题也不给时间戳（条目只有 `sessionId` 与 `cwd`），且只列非活跃会话；没有 `loadSession`，新设备拿不到旧会话内容。
197. ACP 的 `promptCapabilities.image = false`：图片内容块在参数校验阶段就被 `-32602` 拒绝，不能走 ACP image block；`sessionCapabilities` 只有 `close` / `list` / `resume`，`delete` / `fork` / `additionalDirectories` / `loadSession` 全不可用；审批选项只有 `allow_once` / `reject_once`（没有 `allow_always`，"本次会话允许"必须桥自己记忆）。
