## 2. 这一版改了什么（4+1 条）

### 2.1 会话页右上角：模型设置按钮 → 工作区入口（用户原话）

> 「会话页面，右上角有个按钮是模型设置的按钮，改成工作区选择会话，和首页右上角工作区一个功能」

- 那个齿轮点进去的页面标题就是 `模型设置`（`ui/settings_page.dart:121`），所以用户是这么叫它的。
- 现在换成共用组件 `ui/widgets/workspace_entry.dart` 的 `WorkspaceEntryButton` —— **首页顶栏也是这一个**，
  点进去都是 `WorkspacePage`（工作区 + 每个工作区下的会话 + 切换 + 恢复历史会话）。
- 顶栏第二行从 `○本机` 补成 `○本机 · <工作区名>`（名字由 `AppShell` 从 `WorkspaceStore` 取，
  取不到退回路径末段，**不编名字**）。
- 回调由 `AppShell._openWorkspace` 提供：工作区登记表是**壳**持有的，会话页自己再建一份会变成两个真相。
- 「模型设置」没有丢：底部导航的「设置」Tab 还在，会话页报错条里的「去设置」也还在。

### 2.2 产物：只装真正生成的文件（用户原话）

> 「产物这里就应该是产生的文件」

**修前的真实现象**（用户实测）：让模型画图，会话里先冒出三个"产物"，到图生成完都点不开，
最后只能在资料库找到图。

**根因**：ACP 没有 artifact 通知，产物只能从工具调用的文本里正则捞名字。
让模型画图时它会先读 `assets/skills/make-image/SKILL.md`，那份文档正文作为工具结果进了会话，
里面的**示例命令** `node … make-image.mjs "提示词" "输出.png" --ref "参考图.png"` 被当成了文件名。
（把 App 的提取规则原样复刻、喂真源 SKILL.md 跑一遍 → **正好捞出三个名字**：

```
--- make-image/SKILL.md → ["输出.png","参考图.png","const b=require('node:fs').readFileSync('输出.png"]
```

）

**改法**（两道硬门槛，缺一不可）：

1. **候选阶段**（`extractArtifactCandidates`）：名字里带 `'` `"` `=` `(` `)` `;` 等代码字符的直接丢；
   工具输出里带绝对路径的**把路径整段留下**（含"已生成 /data/…/橘猫.png"这种带中文前缀的句子，
   会按"最后一个空格后以 `/` 开头"的规则切出路径）。
2. **核实阶段**（`verifyProducedArtifacts`，新增）：按候选带的路径（或 cwd + 名字）`stat` 一次 ——
   必须是**文件**、**真的存在**、而且 **mtime 晚于本页会话开始时间**（= 这次会话写出来的）。
   三个条件不全 → **直接丢**，不进产物列表。核实通过的产物带上**真实绝对路径**，
   点开/分享都用它（`ArtifactOpener.resolve` 优先走 `LibraryEntry.probe`，只 stat 一个文件，不再扫全目录）。

设备端证据见 §4.2。

### 2.3 「设置 → 外观」的说明文案重写（用户原话）

> 「设置页面外观的表述有问题，浅色那里写着对齐下载站的，不要体现参考别人的字眼」

`ui/pages/settings_tab.dart:157` 的正文从「浅色逐条对齐网站 https://soft.zmm168.top/ 的浅色令牌；…」
改成「浅色：白底玻璃面板 + 青紫点缀，白天和强光下看得清。深色：同一套强调色的深色面，
面板换成更亮的半透明层，夜里不刺眼。」—— 代码注释里的设计出处保留（那是给维护者的，不是给用户的）。

### 2.4 窄屏顶栏溢出（写测试时抓到的真 bug）

会话正在跑 + 已经有产物时，顶栏右边同时挂「停止 / 产物 N / 工作区」。实测自然宽度：

| 元素 | 宽度 |
|---|---|
| 返回 IconButton | 48.0 |
| 停止 TextButton.icon | 81.2 |
| 产物 128 TextButton.icon | 136.6 |
| 工作区 pill | 72.3 |

合计 338.1 + 左右留白 12 = **350.1dp** → **320dp 宽的机型溢出 30px**（测试实测报的就是 30）。
现在两个文字按钮统一压到 32dp 高 / 横向 6dp / 12pt 字（`ChatTopBar._actionStyle`），三者合计约 210dp。
