# 泡泡猫 DSH 手机版 v0.74

**本版就一件事：修好「免费模型（无需 Key）」突然全部不能用。**

## 问题与根因

2026-10-13 手机端报告：免费通道全部返回

```
403 FreeTierError: OpenCode's free tier can only be used from within OpenCode.
```

**这不是"你没配 Key"，是上游又换了验证方式**：它把判断从「看你像不像官方 CLI」
换成了「看你带没带它认得的那种会话号」—— 会话号（`x-opencode-session`）的前 12 位
必须能**解码回一个正常的毫秒时间**；解不出来，就一律判成"不是 OpenCode 客户端"。

而各家实现（包括本 App 从 10-11 起用的那版）都是把这 12 位**用摘要拼出来的** ——
形状一直是对的（`ses_` + 12 位 hex + 14 位 Base62），**含义**不对，所以全被拒。

**修法**：按官方那套时间编码生成这 12 位（`~(BigInt(Date.now()) * 0x1000n + counter)`
取低 48 位），基准**按天取整** —— 同一天内同一会话拿到同一个 id，保住上游的
prompt-cache 亲和。

## 实测（不是照抄结论）

| 请求 | 结果 |
|---|---|
| 摘要派生的会话号 | 403 FreeTierError |
| **时间戳编码的会话号** | **200，真流式吐字** |
| 时间戳编码 + body 不带 `tools` | 403（`bash` + `read` 仍然必需） |
| 时间戳编码 + 不带 `Authorization` | 200（`Bearer public` 可带可不带） |

补过之后的代理端到端打真上游：**200 / 10,824 字节真 SSE**，模型真回了内容；
同一个会话种子两次 → 会话号**完全一致**（缓存亲和没丢）；回归测试 13/13 通过，
并做了反向自检（把代码改回摘要派生 → 测试立刻变红，而旧的形状测试仍然全过）。

## ⚠️ 这条通道的性质没变

它是**实验性**的：4 天内上游变卦 4 次（09-17、10-09、10-11、10-13）。
所以界面上仍然标注「**随时可能失效**」、默认关闭、要用自己开；失败时
**如实说清是哪一环被拒**并给下一步，绝不假装成功。

想要稳定且免费的额度，建议用**注册即得**的那几家（例如智谱 `glm-4.6v-flash` 永久免费）
当**普通厂家**填进来 —— 这条路不依赖任何"伪装"，上游变脸也不受影响。
