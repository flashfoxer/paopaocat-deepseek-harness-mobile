# 一、修好的问题（5 条）

## 修好「历史会话点开是空的」

**之前的问题**：点开一条历史会话，里面**一条内容都没有**，看着像对话被删了。

实际查下来（对话记录一个都没丢）——**磁盘上没有删过任何会话**；"空"是 App 自己造出来的：
你**只是点开过聊天页、或者从首页点了「内置会话」但没发出去**，App 就已经先把会话建到磁盘上了，
于是列表里堆了一批「没标题、点开全空」的空壳，把真正聊过的对话淹掉了。

**现在**：**只点开、没发消息，就不再往磁盘上落会话**；列表里也不再显示一条消息都没有的会话，
并且如实写出「磁盘历史会话 N 条（其中 M 条是空会话，没列出来）」，免得你数一遍发现对不上。
那些已经攒下的空壳**没有被删**（删你目录里的东西是不可逆的，这版不做这个动作）。

## 切模型不再"偷偷换一个会话"

**之前的问题**：在一个会话里切模型，界面提示「会话内切换模型成功（会话未重建）」——
**这句话是假的**：紧接着进程重启、App 开了**另一个新会话**，你刚才那条提问就留在了旧会话里。

**现在**：切模型**不再变成新会话**。App 会记住"我正在用哪个会话"，进程即便因为模型配置
变化而重启，也会**恢复到同一个会话**（上下文还在），并且提示语如实改成
「已切换到 X（会话没重建，上下文还在）」。

## 提问失败时，会话里能看到原因

**之前的问题**：提问失败（上游连不上、被限流……）**只写在诊断日志里**，会话本身一个字都不记。
过一会儿回头看那条会话，只有你发出去的话，没有回答、也没有任何报错 —— 很难不怀疑"对话丢了"。

**现在**：失败原因 App 会自己记一份；重新打开那条会话回看历史时，末尾会出现一条**红色的
「没有回答」**，写着人话原因（需要技术细节也能看到原始报错）。

> 如实说明：这条记录是 App 自己存的，**不在 DSH 的会话文件里**。
> 所以换设备/重装 App 之后，这些失败提示会没有（对话本身不会丢）。

## 连点发送/超时后不再白丢一轮

**之前的问题**：上一条还在回答时又发一条会直接失败；而请求超时之后状态没复位，
下一条又会撞上"已经有一条在飞"，白白丢一轮。

**现在**：超时后会主动把上一轮**取消收尾**，不再让它悬着；发送那段也加了防连点。

## 切模型时不再因为"别的厂家变了"重启会话

**之前的问题**：你去设置里改了**别的厂家**的 Key（或者只是勾了一个新模型），
回到会话里一切换模型，App 会把正在聊的会话**重启一遍**——明明跟这条路由没关系。

**现在**：判据只看**这条路由自己的东西**（它属于哪个厂家、那个厂家的地址和 Key、它自己的模型条目）。
只有这些变了才重启；改别的厂家**完全不动**你正在聊的会话。

# 二、这一版新增（6 条）

## 「工作台」改名叫「创作台」

**之前的问题**：底部那一项叫「工作台」，名字偏办公，和它实际干的事（生图、生视频、短剧、
口播、画图表、小说改游戏）对不上。

**现在**：全App统一叫**「创作台」**（中英日韩四套文案同步改：Studio / スタジオ / 스튜디오）。

## 会话列表能看到时间和用了多少 token

**之前的问题**：会话列表只有会话号，看不出这条会话是**什么时候**的、**用了多少**量。

**现在**：每条会话都显示**时间**（刚刚 / 12 分钟前 / 3 小时前 …）和**用量**
（例如 `12k tok`）。**取不到就不显示那一段** —— 不编一个 `0 tok` 骗你。

## 首页版本号下面多了一条滚动信息栏

**之前的问题**：首页有点空，而且我想公告点什么（新版本、活动、公众号更新）没地方放。

**现在**：首页**版本号下面**多一条信息栏 —— 短的居中静止显示，长的会自己滚动。
点一下能看到**全部**条目，带链接的可以「查看详情」。
这条栏的内容是我在仓库里改一个字就能更新给所有人的（`notice.json`），
**拉不到就什么都不显示**，不会用假内容占位。

## 点一下首页那只猫，它会说一句话

**现在**：点首页的猫咪，它会弹出一句"对话气泡"式的话（点一下换一句，5 秒后自己消失）。
说的话是**本地写死的几句**，不联网、不调模型 —— 所以点一下是**立刻**有反应，
也不会说出没有依据的内容。

## 像素主题整了容（这次是真的不一样了）

**之前的问题**：切到"像素"主题，看起来只是换了几个颜色、圆角变方——**变化不大**。

**现在**：像素主题换的是**一整套视觉**：

* **字体**换成等宽字体（和其他两套皮肤一眼就能分开）；
* 描边**加粗一倍**、面板改成**不透明实心板**（不再是磨砂玻璃）；
* 投影变成**没有模糊的硬方块位移**（贴纸/像素块的观感）；
* 背景多一层**扫描线**（CRT 那种横纹）。

> 说明：没有随包带"像素汉字字体"——中文像素字体一个就 5~10 MB，我们刚把包瘦下来，
> 不能为了一个皮肤加回去。等宽字体是设备自带、中文也覆盖、气质也对的最小代价方案。

## 长按公众号二维码 → 直接唤起微信扫一扫

**之前的问题**：「关于」里那张公众号二维码只能自己打开微信去扫，App 帮不上忙。

**现在**：**长按**那张二维码（下面也写了这行提示），会直接**唤起微信的扫一扫**，
你对着屏幕上的二维码扫一下就行。没装微信、或者被系统拦了，App 会**如实说**
（绝不说"已进入公众号"这种做不到的话）。

## 「不用填 Key 就能聊」这句承诺，重新站住了

**之前的问题**：那句承诺是靠一条**第三方免费通道**（OpenCode Zen 的匿名层）实现的，
而它从 2026-10-13 起被上游反复收紧（一共五次）：模型列表里那批「免费模型」还在，
可**一发消息就失败** —— 更糟的是报错会被翻成"权限 / 套餐"之类的话，让人以为是自己的
Key 或账号有问题，怎么查都查不出。

**现在**：换成 **Pollinations**（`pollinations.ai`）—— 它**自己就开放匿名层**，
README 第一句就是"不用注册、不用 Key"（不是我们去绕什么）。装完**不用做任何设置**：
模型列表里就有「免费模型（无需 Key）」这一组，直接能聊；也可以随时在
「设置 → 模型 → 免费模型（无需 Key）」里关掉。
原来那条 Zen 通道保留成彩蛋（默认关）。**2026-10-16 更新**：它又被上游放开了一轮
（本机实测**能正常回答**），但这是 2026-09-16 起的**第 6 次**改动，时好时坏 ——
所以界面上不再写死"已失效"，而是让你**点一次「通道自检」看此刻通不通**（见下面 0.75+2 那节）。

**要知道的（界面上也写着）**：这一组**只有一个 20B 级模型**（聊天、调用工具都行，
但**不是聪明模型** —— 写小说、长文、画布这类重活它接不住，那些用自己的模型）；
有速率限制；上游是社区项目，随时可能变，变了会**如实报错**，不会假装成功。

## 会话里的 AI，现在能自己去查资料了（联网搜索）

**之前的问题**：手机上的会话其实**本来就有搜索工具**，但那个工具的后端要一把
DeepSeek 官方的 Key —— 没配 Key 的会话，搜索一用就报"没有可用的搜索后端"；
而且界面上也看不出来该怎么补。

**现在**：多了一条**不用填 Key 也能搜**的通道（AnySearch）。打开
「设置 → 模型 → 会话联网搜索」就能用（**默认就是开着的**）；想更稳的额度，
可以用邮箱在 anysearch.com 免费换一把 Key 填进去（可选）。
会话里的 AI 于是能自己搜网页、并把来源链接写进回答。

**要知道的**：① 搜索请求是发到 **api.anysearch.com** 的（这是联网功能，
不是本机算出来的）；② 它**在建会话那一刻**挂上去 —— 改完之后要**开一个新会话**才生效；
③ 匿名层限流较低，搜得太频繁会被限，等一会儿或填一把 Key。

## 会话里的 AI 现在能「分人做事」了（子智能体）

**之前的问题**：手机上的会话其实**本来就带子智能体能力**（把一块子任务交给另一个 agent 实例去做，
它有自己的上下文窗口，干完只把结论拿回来），可 App 里既看不到它、也没有任何开关 ——
想关掉或想指定"子会话用哪个模型"都做不到。

**现在**：「设置 → 模型 → 子智能体」里可以开关，也可以指定子会话用哪个模型
（默认跟随当前会话）。关掉就是彻底关掉（相关的工具与服务一起停用）。

**要知道的**：① 多一层子 agent = **多一份 token 与时间**（子会话也要跑模型），
用免费那条小模型通道时尤其明显；② 改完**只在下一个会话生效**。

**顺带修的**：会话里的联网搜索现在**优先走 App 自带的后端**（不用 Key、匿名即可），
只有老安装包（运行时里没有那个后端）才退回另一条通道 —— 两个搜索入口不会再同时出现。

## 完整包装完还要下 32 MB 运行环境（已修）

**之前的问题**：完整安装包里其实**带着**运行环境，但 App 压根没去读它 ——
第一次打开时仍然让你下 32 MB；网络一慢（比如更新源 20 秒没响应）就直接卡在
「首次使用：准备运行环境」那一页报错。

**现在**：完整包**真的用包里自带那份**：第一屏会写「运行环境随这个安装包自带 ——
不需要联网」，直接在本机解开就完事；**精简包**（不带运行环境的那种）仍旧是
"第一次打开时下载一次"，文案也照旧如实说明。

**另外**：覆盖安装一直都可以（不用卸载）。这一版把运行环境的"内容版本"也升了一格，
所以**覆盖安装后会重新解压一次运行环境** —— 完整包直接从安装包里取（不需要联网），
精简包用本机已有的那份（同样不下载）。这样"会话里免 Key 搜索"这条新能力才会真正生效。

# 三、还没做的

* **音乐播放器 + 后台播放**：这一版**没做**。后台播放要动原生最重的那块（前台服务 +
  通知栏控制），会多一条常驻通知和一组新权限，和我们刚做完的包瘦身、权限最少的方向相反；
  而且本机没设备，**后台音频我验证不了**，没验证过的原生功能不该进包。
  现在的替代：工作区/资料库里点音频**能在 App 内播放**（只是切到后台会停）。
  以后要做的话按三步走：先做 App 内播放列表 → 再加一个专门的播放前台服务 →
  最后才做锁屏控制，每步都真机验证过再往下走。
* **真机验证**（代码这半边都做完了，下面几条要在你手机上跑一遍）：
  ① 只打开聊天页、不发消息 → 磁盘上不该新增会话；
  ② 切模型 → 会话 ID 不变、上下文还在；
  ③ 断网发一条 → 回看能看到「没有回答 + 原因」；
  ④ 超时后再发 → 不再报"已经有一条在飞"；
  ⑤ 首页那条信息栏（需要先把 `notice.json` 推到仓库）；
  ⑥ 点猫咪、切像素主题、长按二维码。
* **`zen/*` 免费通道时好时坏**（2026-09-16 起被上游改过 6 次门禁；2026-10-16 本机实测可用），
  出厂默认路由**没有设成它**（默认是免 Key 的 Pollinations），要不要换仍等你定。

# 三、0.75+1（2026-10-15 晚 · 0.75 周期里的第 1 次未发布迭代）

> **版本号口径**：没发布到仓库的迭代一律记作「当前版本 + 序号」→ 本批是 **0.75+1**。
> 0.75 只有在用户说「发布」之后才正式定稿；发布之后才进入 0.76 周期。
> App 内「设置 → 关于 → 更新说明」里这条仍显示 0.75（给用户看的数字不做 `+1`），内容与本篇逐条对应。

## 长按公众号二维码，不再是一句永远失败的提示

**之前的问题**：长按二维码，屏幕上弹出来的是「对不起，当前页面无法访问」—— 那是**微信自己画的错误页**。
真因是这条指令（`weixin://dl/scan`）属于微信**内部**地址，微信现在不让外部调用它了；而我们这边只判断"系统里有应用接住了这个请求"就当成成功，于是还弹了一句「已打开微信扫一扫」。

**现在**：长按出来三条**真走得通**的路 ——「复制公众号 ID」（去微信搜索框粘贴就能关注）/「把二维码存到相册」（再用微信 扫一扫 → 右上角相册 选这张图）/「仍然试一次唤起微信」（试可以试，结果如实说），并且会先核对**接住的到底是不是微信本尊**。任何情况下都**不会再假装"已经打开了扫一扫"**。

## 换一家模型之后，会话不再"只剩一段摘要"

**之前的问题**：同一个厂家内换模型没事；**换厂家**之后再看这个会话，感觉只剩一段摘要；多次进出又像丢了。

**真因有两层**：① 换厂家**必须重启会话进程**（每家的 Key 与端点是进程启动时注入的，不重启拿不到新 Key）；② 重启后历史只被画进一个**「只读回放」的小框里、没有并进对话** —— 看着就像被摘要了。

需要说清的是：**模型自己的记忆一直都在**（它恢复会话时会把全部记录读回来重建），丢的只是**界面上的可见性**。

**现在**：历史**直接并进消息流** —— 同厂家切、换厂家切、退出重进，看到的都是同一条对话。

## 几个会话来回切之后，点别的功能不会再窜出会话页

**之前的问题**：从工作区点开一条会话，会在页面栈上又压一个会话页，而**底下的旧会话页从来没被关掉** —— 于是在最上面那层点底部导航只会弹掉一层，**露出来的是下面那个会话页**（当时连按三次返回才出去）。

**现在**：任何时刻**栈上只保留一个会话页**。

## 会话面板太透明、打字看不清 —— 改了

**之前的问题**：输入框是一层"7% 白"的半透明（那是卡片的玻璃质感），字压在上面会透出背后的渐变，所以"和底版混在一起"。

**现在**：输入框（会话底部那条，以及全 App 所有输入框）统一换成**不透明的实底**，并加了一条**对比度门禁测试** —— 以后谁再把它调回半透明，测试立刻变红。

## 设置页归纳成 4 组；「检查更新」挪进「关于」

- 以前 15 个板块平铺着，全部收起也要滑两屏；现在收成 **4 组**（模型 / AI 能力 / 外观与语言 / 应用）+ 常驻的「关于」—— **不展开时一屏正好看完**。
- **「检查更新」并进「关于」**，就排在「更新说明」上面：一个查有没有新版、另一个看每版改了什么，本来就是一件事的两半。

## 「记忆」变成了完整的记忆（就是你说"智能体的必备要求"的那条）

- 每条记忆现在可以标**分类**（身份 / 偏好 / 项目与事实 / 不要做的事 / 其它）、**重要度**、**作用范围**（全局，或只在某个工作区生效）；能搜索、能置顶、能一键关闭注入，也能**导入导出 JSON**。
- 新增「**从最近会话里提炼**」：模型读一段真实对话，自己整理出"值得长期记住"的候选，**由你逐条勾选确认**后才写入 —— 它不会背着你偷偷记东西。每次提炼会真实调用一次模型（界面上提前写清），失败或超时都会如实说原因。

## 外观新增「壁纸」

从相册选一张铺满整屏，配两个滑块：**变暗**与**模糊** —— 它们不是装饰，是保证正文仍然读得清的出口（卡片是半透明的，背景一亮字就难认）。也有一键「不用壁纸」。

## 藏了一个彩蛋

首页**连点那只猫 7 下** —— 前 6 下每点一下它都会说一句话（泡泡在**左 / 上 / 右**轮流出现，同时手机**短震**一下）；**第 7 下会长震**，左、上、右**三个泡泡一起弹**，写着「有彩蛋，在设置里」，并且「设置 → 模型」里会多出一块「实验通道 · OpenCode Zen（第三方通道）」。
这条通道在 4 天里被上游改了 4 次、现在基本不可用，从明面上撤下来更好（免得让人"配了却用不了"）；留成彩蛋是因为它的成本只有一个开关 —— 万一哪天上游又放开，打开就能用。

## 顺手修掉的三处老毛病

- 点猫弹出的气泡用了**负 margin**，Flutter 会直接断言崩溃（debug 下一画就抛异常）。它以前没被测到，是这次给彩蛋写测试时才抓出来的。
- 设置页的**长标题**在窄屏上会把整行撑爆（debug 画黄黑条纹、release 把字裁掉）。
- 会话回放以前会把 DSH 注入给模型的**运行时说明**当成"你说过的话"显示出来 —— 现在不会再出现。

# 四、0.75+2（2026-10-16）

> 这一批是 0.75 周期里的第 2 次未发布迭代。技术侧记录在
> [`CHANGES-2026-10-16.md`](CHANGES-2026-10-16.md)。

## 做 PPT 这件事，从"能生成"变成"能拿得出手"

**之前的问题**：生成的 PPT 只有两种样子（封面 + 标题配一列要点），而且**字多了会压出版心** ——
PPT 打开时不会重排，字就叠在一起或者跑到页面外面去了。想画"三张卡片""一条时间线""两栏对比"
"一张柱状图"都做不到。

**现在**：你（和会话里的 AI）只需要写**内容**和**选版式**，排版全部由脚本算：

- **12 种版式**：封面 / 章节页 / 目录 / 要点 / **卡片** / **时间线** / **两栏对比** /
  **关键数字**（92% 那种）/ **数据图**（柱状、条形、堆叠）/ 引用 / **配图** / 结尾。
- **自动排版**：字多了自己**收字号**（正文有 12pt 的可读下限，再放不下就**拆成"（续）"页**）；
  卡片按条数自动分栏；图片按原比例放进框（不拉伸）。
- **6 套配色**（墨蓝 / 海蓝 / 苔绿 / 暖橘 / 莓紫 / 灰阶）+ 可选**换页转场**；
  页脚、页码自动处理（封面和章节页不画页码）。
- 产出仍然是**原生对象**：色块、卡片、柱子、文字在 PowerPoint / WPS 里都能选中、能改颜色改字。
- 顺手修好：**`**这样**` 会真的变成粗体**（以前会把两个星号原样印在幻灯片上）。

**要说清的边界**（界面上/技能里也这么写）：数据图是**用形状画的**，能一眼看懂、能改颜色尺寸，
但**不是** PowerPoint 的"图表对象"（改数据要重新生成）；**没有**逐元素动画、**没有**音频嵌入；
配图只吃**手机上的本地图片**，不联网抓图。

**入口在哪**（用户问「ppt 这个功能放哪了」，于是补了一个明确的）：
* **首页**那条内置会话的第一条就是「做一份幻灯片」（一次显示 4 条，点「换一换」换一组）；
* **创作台 → 工具 → 「做 PPT / 幻灯片」**（这一版新加的，点开有几个可直接用的例子）；
* 也可以在任何会话里直接说「做一份 PPT」——技能会自己接上。
生成后在**资料库**里能找到那个 `.pptx`（App 内看不了它的样子，用「用其它应用打开」交给手机上的 WPS / Office，或者直接分享）。

## 免 Key 那条通道又能用了；「通道自检」也改准了

- **2026-10-16 本机实测**：那条彩蛋通道（OpenCode Zen 的匿名层）**能回答**了 ——
  免费层里 10 个模型，其中 6 个可用（3 个是"你所在地区不开放"，1 个走另一种协议）。
  上游自 2026-09-16 起改过 **6 次**门禁，所以**不承诺稳定**，但也不再说死"已失效"。
- **自检不再"假通过"**：以前它只问一句"模型列表能拉到吗"，而这道门禁**列表永远能拉到** ——
  于是"根本用不了"会被报成"这条通道是好的"。现在它会**真发一句最小的话**（1 个字，
  只打手机本机、不带任何凭据），并且**最多试 3 个模型**，还会把两种完全不同的 403 分开说：
  **"被当成非官方客户端"** 与 **"你所在地区不开放"**（这两句的下一步完全不一样）。
- 自检那一整页的文案以前**没有外语版本**（切到英文/日文/韩文还是中文），这一版补齐了。

## 顺手修好一个会丢更新的毛病

保存配置/索引时如果**两次保存挨得很近**（真机上出现过相隔 21 毫秒），两次会抢同一个临时文件：
先完成的那次把它改名走，后一次就直接失败，**那一次的更新就悄悄丢了**。临时文件名改成一物一名，
并且补了一条"同时保存三次，必须有一个完整落地"的回归测试。
