# 生成一张图片

本技能负责：把一段画面描述变成工作区里的真实图片文件（png/jpg/webp）。
什么时候用：用户说「生成一张图 / 画一张 / 做个图 / 按这张参考图改成 …」。

## 0. 先确认（有问题才问，别追问过头）
- 画面主体、场景、风格、光线、构图、比例（竖屏 9:16 / 横屏 16:9 / 方图 1:1）。
- 有没有参考图（工作区里的文件名，或用户给的图片 URL）。
- 图片里**要不要出现文字**：模型对文字常常写错，要写字的场景先跟用户说清这个风险。

描述已经够清楚时直接生成，别再确认一遍。

## 1. 写提示词
一段话按这个顺序写，中文即可：

`主体 + 动作/姿态 + 场景环境 + 风格（写实/插画/水彩/像素/3D 渲染）+ 光线氛围 + 构图与视角（特写/平视/俯拍/广角）+ 画质词`

示例：
```
一只橘色短毛猫趴在木质书桌上打瞌睡，午后阳光斜射进来，
背景虚化的书架，清新写实风格，暖色调，浅景深近景，高细节
```

反例（别这样）：只写「一只猫」——信息太少，出图随机性大。

### 1.1 一致性锚点（要让"同一个角色/场景"出现在多张图里时，必读）

**问题**：用户要 5 张图讲一件事（同一个人物、同一个房间），一张一张生成下来，
人物长相、发型、衣服每张都不一样 —— 这是多图任务里最常见的翻车，也是**最能一眼看出"业余"**的地方。

**做法（三步，别跳）**：

1. **先定一张"基准图"**（锚点）。用最完整的一段描述生成它，确认后再往下做：
   ```
   角色定妆：短发女性，圆脸，戴细框眼镜，米白色高领毛衣，浅灰背景，正面平视，柔光
   ```
2. **把这段"角色定妆描述"存成一个字符串**，之后每张图的提示词都**原样拼上它**。
   ⚠️ 不要每张重新描写一遍 —— 换一个词（"短发"→"齐耳发"）就会换一张脸。
3. **后续每张图都带上锚点图**（`--ref`）：
   ```sh
   node "$DSH_ANDROID_TOOLBOX/make-image.mjs" \
     "角色定妆：…（原样照抄）+ 她坐在窗边看书，侧光，近景" "看书的她.png" --ref "基准图.png"
   ```
   `--ref` 可以给多张（例如同时给"正脸锚点"和"全身锚点"），要改风格时给"风格参考图"。

**什么必须开新变体**（不要硬套锚点，会出矛盾画面）：
换装、换季节、受伤/脏污、年龄跨度、正脸↔背影、白天↔夜晚。开变体时
**文件名里带上状态**（`小美-冬装.png`、`小美-受伤.png`），并在回复里说明这是新变体。

**场景/道具同理**：同一个房间先用一张定好（墙色、家具布局、光线方向），
后续用 `--ref` 带上它，并在提示词里重复同一句场景描述。

**如实说明**：模型**不保证 100% 一致**。如果几轮下来还是差得多，
就如实告诉用户"同一角色多图一致的稳定性有限"，并提出替代方案
（把差异缩到最小：改角度不改造型；或改用一张图里画多个分格）。
**不要**假装一致、也不要把明显不像的图说成"基本一致"。

## 2. 生成
```sh
node "$DSH_ANDROID_TOOLBOX/make-image.mjs" "提示词" "输出.png"
node "$DSH_ANDROID_TOOLBOX/make-image.mjs" "提示词" "输出.png" --size 2K --ratio 16:9
node "$DSH_ANDROID_TOOLBOX/make-image.mjs" "把背景换成夜景，其余保持不变" "输出.png" --ref "参考图.png"
```
- `--size`：1K / 2K / 3K / 4K，默认 2K。
- `--ratio`：1:1（默认）/ 3:4 / 4:3 / 16:9 / 9:16 / 2:3 / 3:2 / 21:9。
- `--ref` 可重复多次，值是**本地文件路径或 URL**；给了它就是从参考图改图（图生图/多图合成）。
- 模型是 `agnes-image-2.5-flash`，默认就是这个，一般不用传。

## 3. 自检
```sh
node -e "const b=require('node:fs').readFileSync('输出.png');console.log('字节',b.length,'魔数',b.subarray(1,4).toString())"
```
- 魔数应为 `PNG`，大小几百 KB 以上。
- 如果有看图能力，顺便核对一下画面是否和提示词一致；不一致就改提示词重生成一次。
- 没生成出来就不要交付路径。

## 4. 交付
回复里给：产物**路径原样**、用的提示词、比例与档位。用户可在「资料库」预览和分享。

## 凭据与价格口径（必须按这个说）
- 脚本读环境变量 `AGNES_API_KEY`。**没配 Key 时脚本会直接报中文错误并打印注册地址**
  （`AGNES_REGISTER_URL`，默认 https://platform.agnes-ai.cn）。
  这时要把这句原话如实转告用户：需要先注册并配置 Key。**不要**退化成「那我给你写个提示词吧」。
- 图像模型当前处于免费档：官方原文是「所有支持的输出分辨率档位和输入参考图片当前均免费」。
  这是**当前/限时**口径，官方注明「免费政策如有调整，以平台最新公告为准」——
  **不要说成「永久免费」**。

## 诚实约束
- **绝不编造图片链接**，**绝不**拿占位图/空白图冒充结果。
- 生成失败（网络、额度、内容被拒）就把脚本输出的**真实报错**贴出来，说明是脚本报的还是平台报的。
- 这台设备上没有 python / imagemagick / ffmpeg，不能本地裁剪、抠图、格式转换；要这些只能说明做不到，
  或改用 `--ref` 让模型重画一版。
